# Wedding invitation website

Extract the ZIP and keep the files together with the `assets` folder. Open `index.html` in a browser to preview the invitation. The opening screen uses the supplied couple photo as a full-screen background and shows only the clickable words “YOU ARE INVITED.”

The invitation includes a continuously moving gallery of the seven couple photos. Each image is shown uncropped, with no slideshow arrows, dots, or counter. The locally included **River in Flow** MP3 plays from the website files without YouTube. The RSVP section prepares an email to `htetthayapekyaw@gmail.com`; guests must press Send in their email app. The venue section includes a Google Map.

The opening portrait is `assets/opening-couple.jpg`. Keep the complete `assets` folder beside `index.html` when uploading the site. This package is the website source; it does not create a live website or a Google Form.
